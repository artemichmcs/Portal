# Портал — демо-сайт антикафе

Запуск из папки проекта: `npm start`

Откройте http://localhost:3000. Установка пакетов не требуется; нужен Node.js.
В Windows также можно запустить start.cmd двойным щелчком.
Чтобы остановить сервер, нажмите Ctrl+C в его терминале.

Адаптивная страница, фильтры развлечений, окна с подробностями,
контакты для бронирования во ВКонтакте и MAX, ответы на вопросы,
ссылка на клуб в Яндекс Картах.

Информация и цены: https://anticafeportal.taplink.ws/
Фотографии Unsplash — иллюстрации VR, не фотографии самого клуба.
Для загрузки фотографий и шрифта нужен интернет; текст и интерфейс работают локально.
Бронирование подтверждает администратор клуба, сайт не отправляет заявки автоматически.
